Напишите функцию main в модуле main, которая отвечает за основную логику проекта и связывает функциональности между собой.

3. Получить информацию о транзакциях из XLSX-файла

Функции:
1. src/category_operations.py - process_bank_operations(Подсчитывает
количество операций по заданным категориям на основе поля
'description')
2. src/search_operations.py - process_bank_search(Ищет операции
в описании которых есть заданная для поиска строка)
3. src/decorators.py - log(Декоратор для логирования вызовов функций)
4. src/external_api.py - convert_transaction_amount(Конвертирует сумму транзакции в рубли (RUB))
5. src/generators.py:
- filter_by_currency(Фильтрует транзакции по коду валюты)
- card_number_generator(Генератор номеров банковских карт в заданном диапазоне)
6. src/logger_config.py - setup_logger(Настройка логгера)
7. src/masks.py:
- get_mask_card_number(Маскирует номер карты)
- get_mask_account(Маскирует номер счета)
8. src/processing.py:
- filter_by_state(фильтрация по статусу)
- sort_by_date(Сортирует операции по дате)
9. src/utils.py - load_transactions_from_json(Загружает данные о транзакциях из JSON-файла)
10. src/widget.py:
- mask_account_card(Маскирует номер карты или счета в строке формата "Тип Номер".
  Возвращает строку без изменений, если не удалось определить тип и номер)
- get_date(Преобразует дату из формата ISO в формат ДД.ММ.ГГГГ.)
11. src/transactions/csv_reader.py - read_csv_transactions(Считывает финансовые транзакции из CSV-файла)
12. src/transactions/excel_reader.py - read_excel_transactions(Считывает финансовые транзакции из файла Excel)
13. src/transactions/file_reader.py - read_transactions(Считывает транзакции из файлов CSV или Excel)

Файлы:
1. data/operations.json
2. data/transactions.csv
3. data/transactions_excel.xlsx
